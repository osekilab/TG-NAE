# Computing NAE with Transformer Grammar

Repository for computing Normalized Attention Entropy (NAE) with Transformer Grammar (TG).

Official implementation for the ACL 2025 paper:
**"If Attention Serves as a Cognitive Model of Human Memory Retrieval, What is the Plausible Memory Representation?"**

## Code Release

The code will be available before the ACL 2025 conference.

**Paper**: [arXiv:2502.11469](https://arxiv.org/abs/2502.11469)
